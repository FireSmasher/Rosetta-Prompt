# Model selection, personal overrides (example)

Copy this file to `model-selection.local.md` in the same folder and edit it. The copy stays on
your machine: it is gitignored and only ever read locally. Any table below replaces the default
table of the same name in `model-selection.md`, whole (except `lab`, see below), so keep every row you still want.

Delete any table you do not want to override.

In `lab`, every row is `model.level | a job from your own week ;; why it is worth it`. The Effort
lab in the app shows that job beside the maker's own quote for the same level, so write jobs you
would recognise. Unlike the other tables, `lab` merges row by row: a level you do not list keeps
its shipped neutral job. Levels per model are in `lab-levels` in `model-selection.md`. The quotes,
caveats and cost figures are the maker's and stay in `model-selection.md`; do not copy them here.

```rubric
@table lab
opus.low | File 40 scanned documents by fixed rules ;; a misfile costs you later
opus.medium | Write a first note to someone who could open a door ;; one shot at a first impression
opus.high | Find why a scheduled job dies silently at night ;; the cause could be anywhere
opus.xhigh | Wire an application flow end to end ;; a bad submit is public
opus.max | Check a job offer against your permit's limits ;; a wrong answer risks residence
```
